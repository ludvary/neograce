# NeoGrace

An xmgrace-style scientific plotter in Python + Qt (PySide6). Same layout, buttons and workflow as xmgrace, with a modern interface, light and dark themes, anti-aliased rendering, transparency, and undo/redo. It reads and writes Grace `.agr` files.

## About the code

This code was mostly generated by Claude. I have gone through most of the core code, simplified it a lot and tested it, but I haven't reviewed every line. If something looks wrong, feel free to open an issue.

The python is mostly written in a deliberately plain way: explicit loops, ordinary classes with every member spelled out, named methods instead of lambdas, no list comprehensions. It is not the most idiomatic or compact python.

## Run

    pip install -r requirements.txt
    python run.py                               # empty graph
    python run.py data.dat                      # x y columns, like `xmgrace data.dat`
    python run.py -settype xydy data.dat        # x y dy with error bars (also xydx, xydxdy, xydydy, ...)
    python run.py -nxy data.dat                 # x y1 y2 y3 ... -> one set per column
    python run.py -block data.dat -bxy 1:3      # pick columns
    python run.py old_plot.agr                  # open a Grace project

## LaTeX labels

Every string (titles, axis labels, legends, text objects, ...) can be typeset by a real LaTeX installation. Write it like in a LaTeX document, with math between `$...$`:

    Time $t$ (\textmu s)          $\langle x(t)\,x(0)\rangle$          $S(q) = \int_0^\infty g(r)\,e^{iqr}dr$

Plot → Plot appearance → Text typesetting:

- *LaTeX for strings containing $…$* (default): strings with `$` go through LaTeX, the rest use Grace codes.
- *LaTeX for all text*: everything, including tick labels, so the whole figure is in the document font.
- *Grace codes only*: no LaTeX.

The LaTeX preamble (same dialog) can load packages, e.g. `\usepackage{siunitx}` or a font package; amsmath, amssymb and xcolor are always loaded. This needs `latex` and `dvisvgm`, which come with TeX Live and MiKTeX (Edit → Preferences can point to the folder and test it). Labels are compiled in the background and cached on disk, so each string is compiled only once; until it is ready the plain text is shown. Exports wait for LaTeX, and the result stays vector in PDF, SVG and EPS. If a label has a LaTeX error, the status bar shows the error and the plain text is drawn instead.

## Fine placement

Click an axis label, title, subtitle, legend or drawing object on the page to select it (dashed outline), then drag it, or use the keyboard:

- arrow keys: move by 0.001 of the page (Shift: 0.01, Alt: 0.0002)
- `[` and `]`: rotate by 1° (Shift: 15°, Alt: 0.1°)
- Esc: deselect; Delete: delete a selected drawing object

The status bar shows the exact offset and angle. The same values can be typed in: label offsets and angles in Axis properties (Axis label & bar, Tick labels: angle, offset, label every Nth tick), title and subtitle offsets/angles and the legend layout (row spacing, sample length, padding, border width, reverse order) in Graph appearance.

## Using it

- The left button column works like xmgrace: Draw, Zoom, AS, Z/z, arrows, AutoT, AutoO, ZX/ZY, AX/AY, PZ/PU.
- Double-click a set, axis, title, legend or drawing object to open its dialog.
- Drag the legend or any drawing object to move it. The mouse wheel zooms around the cursor (Shift: Y only, Ctrl: X only); middle-drag pans. Esc cancels the current mouse mode.
- Undo / redo everything: Ctrl+Z / Ctrl+Shift+Z (or Ctrl+Y), or the arrows at the left of the top bar.
- Autosave: Edit → Preferences (on/off, interval, backup copy or saving the file itself, folder for unsaved work).
- Text supports Grace codes: `\S` superscript, `\s` subscript, `\N` normal, `\x` greek, `\f{Times-Italic}` fonts (e.g. `\xm\f{}s` gives µs).
- Grace files: open any `.agr`; File → Save writes it back as `.agr`. Save as… offers `.ngr` or `.agr`, and File → Export as Grace project always writes `.agr`. Things Grace can't store (opacity) are kept in `#neograce` comment lines that xmgrace ignores.

## Features

**Data:** ASCII import (single set, NXY, block data with any column combinations like `1:2 2:3 1:3`), all Grace set types (xy, xydx, xydy, xydxdx, xydydy, xydxdy, xydxdxdydy), a spreadsheet editor, formula sets, evaluate expression, ASCII export.

**Analysis:** non-linear curve fitting (Levenberg–Marquardt, presets, bounds, weights, parameter errors), regression (polynomial, exponential, power, logarithmic), running averages, differences, integration, interpolation/splines, FFT, histograms, correlation, sorting, sample points, geometric transforms. Fits and transformations can be restricted to a region.

**Appearance:** symbols, lines, opacity, x and y error bars (symmetric or asymmetric, both sides or one), fill under curves (as polygon or to a baseline), annotated values, legends, titles, fonts, tick marks, grids, log and inverted axes, alternate axes on top/right with tick label formulas (e.g. `1240/x`), multiple graphs and Arrange, page size, 22 colour themes (View → Theme, Ctrl+T).

**Drawing objects** (Window → Drawing objects, Ctrl+D): text, lines, arrows, boxes and ellipses, placed with the mouse, in page coordinates or in the data coordinates of a graph.

**Regions** (Edit → Regions): polygons or one side of a line, drawn with the mouse or typed in.  Kill, extract or count the points inside, or restrict fits and transformations to them.  Regions are shown on screen only, like in Grace.

**Output:** PDF, SVG, PNG, JPEG and EPS (EPS needs `pdftops` or `gs`).
